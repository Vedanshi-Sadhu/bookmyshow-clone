# BookMyShow Clone 🎟️

A simplified clone of the BookMyShow platform built using **JavaScript**, **Node.js**, and **npm**. This project simulates a basic movie booking system, helping me strengthen my full-stack development skills.

---

## Features

- Browse available movies
- View showtimes
- Book tickets
- Basic seat selection (optional)
- Responsive layout

---

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Package Manager**: npm
